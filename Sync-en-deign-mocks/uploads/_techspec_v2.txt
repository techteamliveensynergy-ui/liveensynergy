1. Executive Summary &amp; Architecture Overview


Live-En-Synergy is a three-sided sponsorship marketplace connecting brands, artists/event organisers, and audience members for live events [cite: 3, 4]. Brands fund sponsorship campaigns; artists and organisers receive funding and guaranteed attendance; audience members receive rewards (e.g., ticket reimbursements) following physical attendance verification [cite: 3, 4].


The system architecture comprises four isolated portals with distinct role-based permissions and data isolation [cite: 6], alongside a multi-page public website [cite: 19].

Key Operational Views



6.1 Matching Engine View


Admin reviews active Brand Campaigns and open Artist Events side-by-side [cite: 27]. Admin assigns one campaign to one event, establishing a single active reward rule per campaign [cite: 27, 28].



6.2 Verification &amp; QR Code Generator View


Admin generates a venue-specific QR code per event for physical check-in fallback [cite: 18, 30]. Admin retains full manual override capability to mark audience attendance when box-office or organiser data is unavailable [cite: 18, 32].



6.3 Reward Approval &amp; CSV Export View


Admin reviews two-step verified audience members [cite: 17]. Upon approval, the system adds recipient details (Name, Bank Details, Reward GBP) to a payout queue, exportable as a CSV file for manual bank transfer disbursement [cite: 18, 24].
